
### Scene Setup Instructions for Modular Teleportation System

1. **Create Your Scenes**:
   - Example: "Town_Exterior", "Hospital_Interior"

2. **Set Up Player Prefab**:
   - Make sure your player has the tag "Player".

3. **Place DoorwayTeleport on Trigger Colliders**:
   - Assign the target scene name.
   - Set the spawn position for where the player should appear.

4. **Add GameManager and FadeManager to the Initial Scene**:
   - GameManager: Handles transitions and player positioning.
   - FadeManager: Add CanvasGroup to your fade screen and assign it.

5. **Set Up UI Prompt**:
   - Create a Canvas with a text object ("Press E to Enter").
   - Hook this to the UI_Prompt script.

6. **Make Sure All Scenes Are Added to Build Settings**:
   - Go to File > Build Settings > Add Open Scenes.

You're good to go!
